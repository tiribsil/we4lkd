## Passo a passo do que acontece no módulo de relatórios (reporting) [EXTERNO]

Este módulo (Fase 4) transforma os dados técnicos em um documento legível para pesquisadores humanos.

1. **Coleta de Visualizações**:
   - Gera gráficos de tendência de similaridade para os principais compostos.
   - Cria tabelas comparativas de antecipação.

2. **Preenchimento de Template LaTeX**:
   - Utiliza um template profissional para organizar os resultados.
   - Inclui informações sobre o corpus, o modelo selecionado e os principais candidatos a descoberta.

3. **Compilação**:
   - Organiza os arquivos necessários para a geração do PDF final (as figuras e o código LaTeX), salvando tudo em `data/{disease}/validation/reports/`.
